# DIY电脑配机工具 —— 项目分析报告
## 一、定位
一句话定位： 一个把「网页版装机配单工具」封装成「纯离线桌面小软件」的工具，面向直播装机、门店配单、个人 DIY 装机场景，主要想仿制各DIY圈内使用的Excel报价单。
它不是什么：
- 不是商业化产品（没有付费/授权/多用户体系）
- 不是企业级协作工具（明确设计为多机各自独立、数据互不共享）
- 不是通用装机软件（没有京东/淘宝接口、没有在线报价、没有自动查价）
它就是一个 内部自用 / 小团队分发 的垂直小工具。
## 二、项目来源与形态
- 前身是网页版工具，用 Electron（44.4.5）+ Vue 3 + Element Plus 套壳改造
- 交付形态：`electron-builder` 打出绿色版目录（约 240MB）+ 手动压缩的 免安装 ZIP（152.2 MB） ，解压双击 exe 即用
- 无安装程序、无自动更新、无代码签名证书
- 数据存放：程序目录旁的`data` 文件夹（Electron 默认 userData 被改成 exe 同级）
## 三、作用和优点
1. 纯离线、数据自持 ——员工电脑各自安装，互不影响，符合"数据互不共享"的硬需求；断网可用，数据不透明上云。
2. 核心配单功能完整 ——9 大硬件分类 + 4 自定义行、型号联想、数量/价格编辑、小计/合计、杂项费用（四种计费方式 + 抹零）。
3. 直播友好的"区域剥离" ——DIY 配单表可弹出独立窗口，配合直播软件单独采集画面，且与主界面实时同步；这是网页版没有、桌面版做的特色改造。
4. 高自由度呈现定制 ——DIY 卡片每一处文本可单独染色、单独调字号（12 档预设 + 自定义 + 迷你卡等比例预览），满足上播时"放大某行、高亮重点"的实际需求。
5. 兼容性校验 + 型号详情卡 ——本地库检测硬件兼容性、展示基础参数，配单时降低搭配错误率。
6. 备份/恢复 ——全部个人设置可打包成`.diybak` 转给他人，换机迁移方便。
7. 对非技术用户友好 ——操作习惯统一（选色/选字号后"点格子"的交互和学习成本低），工具内操作提示丰富，这是反复打磨过的结果，DIY配置界面的操作模式也跟excel类似。
## 四、特点
- "网页变窗口"但不溶血 ：无边框一体化圆角窗口、页面自绘阴影、隐藏滚动条等，视觉上不像浏览器套壳
- 大改动的健壮性设计 ：方向键全链路导航、剥离窗口防关闭/防误触、导出弹窗防连点的多重兜底逻辑
- 依赖单一化 ：核心功能几乎全在`www/app.js` （约 7000+ 行）单文件内，数据全靠`localStorage` ，理念是"简单可靠"
## 五、未完善与局限
1. 分发与更新原始 ：没有安装包、没有自动更新。改一个 bug 就要重新打包、重新分发、员工手动替换；版本错乱风险由人工承担。"重新做成软件"的流程依赖本机环境手动作业。
2. 体积偏大 ：152MB ZIP / 240MB 绿色版，只是为了几个配单表页内置了整个 Chromium；对机能低的老电脑不友好。
3. 无代码签名 ：解压运行大概率触发 Windows SmartScreen "未知发布者"提示，首次信任成本高，也容易让员工误以为有毒。
4. 数据层脆弱 ：全部存`localStorage` / 文件缓存，无数据库、无事务、无自动备份、无损坏恢复。数据损坏或误清空即丢；也不支持多人共享/服务端备份（这是特性，也是风险）。
5. 依赖环境耦合 ：代码里预留了浏览器网页版分支，但新功能（字号/剥离等）都沿用"本地缓存 + 窗口广播"机制，未来若想联网同步，几乎要重写数据层。
6. 功能边界硬编码 ：9 大硬件分类、杂项计费模式、字号档位/缩放比（0.7）等写死在代码里，改需求需动源码重打包。
7. 单文件臃肿 ：`app.js` 7000+ 行、无模块拆分、无单元测试、无日志系统。能用、够用，但后续维护和排查问题（如之前方向键、剥离同步类 bug）全靠人工读码推断，越改越容易出回归。
8. 无错误上报 ：剥离窗口锁定、缓存写入失败等异常静默吞掉或仅弹提示，出问题只能让用户口头描述，无法远程定位。
9. 代码签名环节是"占位式" ：打包时执行了 signtool，但用的是本地测试签名，不是正式 CA 证书。
## 六、一句话总结建议
这是一个 方向正确的个人/小团队生产工具 ：在 分发、更新、数据安全、可维护性 四个维度仍是"原型级"——它当前最大的风险不在功能，而在"改一处 → 重打包 → 重新分发"这套手工链路，以及 localStorage 承载全部用户资产的单点风险。若继续使用，建议至少补上：正式签名证书、自动更新通道、数据定期自动备份、以及对`app.js` 做模块化拆分。
